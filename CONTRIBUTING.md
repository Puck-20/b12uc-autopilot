# Contributing

This is a personal hobby project built for the MSI 15 B12UC. While it's specific to this laptop, the structure can serve as a template for other systems.

## For B12UC Users

If you find a bug, have a performance improvement, or discover a better configuration, feel free to open an issue!

## For Other Laptop Models

Feel free to fork and modify this for your own setup. The script structure is adaptable — just swap out:
- ThrottleStop profiles
- NVIDIA GPU profiles (or AMD equivalent)
- Hotkeys
- Display settings
- Any laptop-specific AppIDs

**Tips for adapting:**
1. Modify the config section at the top of `CopilotThrottleStopToggle.ahk`
2. Create your own ThrottleStop and GPU profiles
3. Adjust the refresh rates and power settings for your screen
4. Test thoroughly before adding to autostart

This project uses AI assistance for development — if you do the same, that's totally fine. Just test it well!
